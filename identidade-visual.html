Como usar a identidade

  1. Escolha uma direção visual.
  2. Defina uma paleta que tenha contraste suficiente.
  3. Use uma família para títulos e outra para textos quando fizer sentido.
  4. Repita componentes e espaçamentos para criar consistência.
  5. Adapte a linguagem à empresa sem perder a organização.

Para projetos de clientes

O laboratório é uma ferramenta de referência. A direção escolhida pode ser enviada como briefing e depois refinada no desenvolvimento final.

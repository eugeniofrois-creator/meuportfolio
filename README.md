# EC Criações — Landing Page

Projeto desenvolvido como **exercício prático de programação web**, com foco na construção de uma landing page e de páginas complementares para um portfólio demonstrativo.

A proposta é praticar a organização de conteúdo, a identidade visual, a navegação e as interações de uma interface web responsiva.

## Objetivos do exercício

* Estruturar páginas com HTML e aplicar estilos com CSS.
* Adaptar o layout para diferentes tamanhos de tela.
* Implementar interações com JavaScript.
* Organizar arquivos, imagens e componentes compartilhados.
* Praticar versionamento com Git e publicação pelo GitHub Pages.

## Recursos

* Landing page com acesso a páginas de serviços, projetos e identidade visual.
* Modelos demonstrativos de sites para diferentes atividades.
* Laboratório visual para configurar textos, cores, fontes e layout.
* Exportação de referências em PNG, SVG, HTML e JSON.
* Assistente automático por opções e palavras-chave, com encaminhamento opcional ao WhatsApp.
* Navegação entre páginas com controles de retorno.

Os modelos e as interfaces têm finalidade demonstrativa. O laboratório exporta uma referência e uma base HTML, não um sistema completo para produção. O assistente usa regras locais, sem IA generativa.

## Tecnologias

|Tecnologia|Aplicação|
|-|-|
|HTML5|Estrutura e conteúdo das páginas|
|CSS3|Layout, responsividade e identidade visual|
|JavaScript|Navegação, laboratório e assistente automático|
|JSON|Catálogo de imagens e configurações exportadas|
|Git e GitHub|Versionamento e organização do código|
|GitHub Pages|Publicação estática|

O pacote também inclui um painel local opcional em Python/Tkinter para auxiliar na atualização dos arquivos pelo Git. O site funciona independentemente desse painel.

## Estrutura principal

```text
landing-page.html       Página de entrada
servicos.html           Apresentação demonstrativa dos serviços
projetos.html           Projetos e modelos de exemplo
laboratorio.html        Configurador visual
identidade-visual.html  Guia visual
assets/                 Imagens e arquivos da marca
content/images.json     Catálogo de imagens
Painel-EC/              Aplicativo local opcional de atualização
```

## Identidade visual

## Observações

* Este README descreve a edição brasileira do exercício.
* O laboratório guarda um rascunho no navegador. Evite inserir dados sensíveis.
* O WhatsApp só abre quando o visitante escolhe o encaminhamento. Arquivos devem ser anexados manualmente.
* O site não inclui autenticação, banco de dados próprio ou processamento de pagamentos.
* Recursos de terceiros devem manter suas licenças e atribuições aplicáveis.
* Acessibilidade, privacidade e compatibilidade devem acompanhar as próximas revisões. A existência do projeto não representa certificação de conformidade.
